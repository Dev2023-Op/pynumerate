# Module creation guidelines

## Requirements
You will be required to tick of the following when you submit your module:
- written in python
- works on Linux
- not a duplicate
- asks for an input if a flag is not received
- has a install script
- installs into the /usr/lib/pynumerate/modules folder

## Submitting Your Module
When your submitting your module create an issue using the new module template.
Once you have chosen this template change the title to New module: (NAME OF YOUR MODULE)
If we have approved of your module we will add it to the module store so that it can be installed.
